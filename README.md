# CodeTrace

Step-by-step Python execution visualizer.

- **Frontend:** Built with React 19, Vite, Tailwind CSS, Lucide icons, and Monaco Editor in [`./frontend`](./frontend).
- **Backend:** Built with Python 3.12, FastAPI, Pydantic v2, Docker sandbox, Redis rate limiting, and PostgreSQL in [`./backend`](./backend).

For full backend architecture, security specifications, API reference, and setup commands, see [backend/README.md](backend/README.md).
